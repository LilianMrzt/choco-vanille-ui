# CSS Variables

The complete list of every CSS custom property exposed by `@my-org/ui-kit/styles.css`.
All values are read directly from the theme source — this page updates automatically when tokens change.

**Naming rule:** `--{category}-{token}`, the token kept as-is (camelCase) — e.g. `vars.color.primaryHover` → `--color-primaryHover`.

Color and shadow tokens are **theme-dependent** (Light / Dark columns). All other tokens are identical across themes.
