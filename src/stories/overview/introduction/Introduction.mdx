# @choco-vanille/ui

A React 19 component library built with **Vite**, **Vanilla Extract** (zero-runtime CSS-in-TS) and **Base UI** primitives.

---

## What is it for?

`@choco-vanille/ui` is a personal UI kit. Its purpose is to centralise reusable UI building blocks so that every project benefits from:

| Benefit | Details |
| --- | --- |
| 🎨 **Visual consistency** | A single design token system (colours, spacing, radii, typography, shadows…) shared across all projects. |
| ⚡ **Development speed** | Accessible, typed and documented components ready to use — no need to reinvent the wheel. |
| ♿ **Accessibility** | Components follow WCAG standards and are audited with axe-core in every story. |
| 🔒 **Type-safety** | Tokens, props and variants are fully typed — errors are caught at compile time. |
| 🌗 **Light / Dark themes** | Dark mode follows the OS preference (`prefers-color-scheme`) by default and can be forced per subtree. |

## Quick start

For a React application, wrap the application with `ThemeProvider`. It applies
the default document-level theme so components and body-mounted portals share
the same light/dark mode.

<Source
  language="tsx"
  code={`import { Button, ThemeProvider, Typography } from '@choco-vanille/ui';

export function Example() {
  return (
    <ThemeProvider>
      <Typography variant="h1">Hello 👋</Typography>
      <Typography variant="p">A typography primitive.</Typography>
      <Button variant="contained" color="primary" label="Primary action" onClick={() => alert('Clicked!')} />
    </ThemeProvider>
  );
}`}
/>

## Theming — overriding tokens

All tokens are exposed as **CSS custom properties** on `:root` (e.g. `--color-primary`, `--space-md`, `--radius-sm`).
Override them globally in your CSS to rebrand the kit without touching any component code:

<Source
  language="css"
  code={`:root {
  --color-primary: oklch(0.55 0.2 250); /* full rebrand */
  --radius-md: 0.25rem;                 /* sharper corners */
}`}
/>

In your `*.css.ts` files (Vanilla Extract), access tokens via the `vars` object for full autocomplete:

<Source
  language="ts"
  code={`import { style } from '@vanilla-extract/css';
import { vars } from '@choco-vanille/ui';

export const card = style({
  backgroundColor: vars.color.card,
  color:           vars.color.cardForeground,
  padding:         vars.space.lg,
  borderRadius:    vars.radius.md,
  boxShadow:       vars.shadow.sm,
});`}
/>

## Repository structure

```
src/
├── components/       # Components (actions/, foundation/, overlay/, …)
├── theme/
│   ├── tokens/       # Raw tokens (colors, spacing, radii, typography, …)
│   ├── colors/       # light.ts / dark.ts → semantic token mapping
│   └── contract.css.ts  # Typed CSS contract + theme registration
├── stories/          # Storybook documentation (MDX + stories)
└── index.ts          # Public library entry point
```

---

## Adding a component

Place the new component in `src/components/<group>/<name>/`, re-export it from `src/index.ts`, and add a `*.stories.tsx` to document it.
