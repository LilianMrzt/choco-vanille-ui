<Subtitle>
Interactive action component with support for leading and trailing icons, visual variants, semantic colors and sizes.
</Subtitle>

Use `variant` for the visual style, `color` for the semantic color, `size` for dimensions, and `startIcon` / `endIcon` to add icons. For an icon-only button, prefer the `IconButton` component.

<Source
  language="tsx"
  code={`import { Button } from '@my-org/ui-kit';

<Button variant="contained" color="primary" label="Save" />
<Button variant="contained" color="destructive" label="Delete" />
<Button variant="outlined" color="primary" size="sm" label="Cancel" />
<Button variant="contained" color="primary" startIcon="mdi:plus" label="Add" />
<Button variant="ghost" color="secondary" endIcon="mdi:arrow-right" label="Next" />`}
/>

## Accessibility

| Prop / Attribute | Required | Notes |
| ---------------- | -------- | ----- |
| `label` | ✅ Required | Becomes the button's accessible name — always provide a meaningful, action-oriented value. |
| `disabled` | No | Keeps the button visible and announced by screen readers — prefer over hiding the element. |
| `aria-*` | No | All native `<button>` ARIA attributes are forwarded to the underlying element. |

## Variant reference

| Variant      | Usage                                             |
| ------------ | ------------------------------------------------- |
| `contained`  | Primary action — highest visual emphasis (CTA).   |
| `outlined`   | Secondary actions — lower emphasis.               |
| `ghost`      | Inline / toolbar actions — minimal chrome.        |

## Color reference

| Color         | Usage                                               |
| ------------- | --------------------------------------------------- |
| `primary`     | Brand action — main theme color.                    |
| `secondary`   | Neutral actions — low visual priority.              |
| `destructive` | Irreversible actions — deletions / danger.          |
| `success`     | Confirmation — successful validations or creations. |
| `warning`     | Caution — moderate-risk actions.                    |
| `info`        | Informational actions.                              |

## Size reference

| Size | Height | Usage                               |
| ---- | ------ | ----------------------------------- |
| `sm` | 36 px  | Compact UI, inline actions.         |
| `md` | 40 px  | Standard forms and dialogs.         |
| `lg` | 44 px  | Hero sections, prominent CTAs.      |
