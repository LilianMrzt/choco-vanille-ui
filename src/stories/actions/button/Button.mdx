Utilisez `variant` pour le style visuel, `color` pour la couleur thématique, `size` pour les dimensions, `startIcon` / `endIcon` pour ajouter des icônes. Pour un bouton icône seul, préférez le composant `IconButton`.

<Source
  language="tsx"
  code={`import { Button } from '@my-org/ui-kit';

<Button variant="contained" color="primary" label="Enregistrer" />
<Button variant="contained" color="destructive" label="Supprimer" />
<Button variant="outlined" color="primary" size="sm" label="Annuler" />
<Button variant="contained" color="primary" startIcon="mdi:plus" label="Ajouter" />
<Button variant="ghost" color="secondary" endIcon="mdi:arrow-right" label="Suivant" />`}

## Variant reference

| Variant      | Usage                                              |
| ------------ | -------------------------------------------------- |
| `contained`  | Action principale — CTA le plus visible.           |
| `outlined`   | Actions secondaires — moins d'emphase.             |
| `ghost`      | Actions inline / barre d'outils — chrome minimal.  |

## Color reference

| Color         | Usage                                              |
| ------------- | -------------------------------------------------- |
| `primary`     | Action de marque — couleur principale du thème.    |
| `secondary`   | Actions neutres — priorité visuelle faible.        |
| `destructive` | Actions irréversibles — suppressions / danger.     |
| `success`     | Confirmation — validations, créations réussies.    |
| `warning`     | Avertissement — actions à risque modéré.           |
| `info`        | Information — actions informatives.                |

## Size reference

| Size      | Height | Usage                              |
| --------- | ------ | ---------------------------------- |
| `sm`      | 36 px  | UI compacts, actions inline.       |
| `default` | 40 px  | Formulaires et dialogues standard. |
| `lg`      | 44 px  | Sections hero, CTA proéminents.    |
