  Composant d'action interactif avec support des icônes de début et de fin, des variantes visuelles et des tailles.
</Subtitle>

Utilisez `variant` pour le style visuel, `size` pour les dimensions, `startIcon` / `endIcon` pour ajouter des icônes. Pour un bouton icône seul, préférez le composant `IconButton`.

<Source
  language="tsx"
  code={`import { Button } from '@my-org/ui-kit';

<Button variant="default" label="Enregistrer" />
<Button variant="destructive" label="Supprimer" />
<Button variant="outline" size="sm" label="Annuler" />
<Button variant="default" startIcon="mdi:plus" label="Ajouter" />
<Button variant="ghost" endIcon="mdi:arrow-right" label="Suivant" />`}
/>

## Variant reference

| Variant       | Usage                                             |
| ------------- | ------------------------------------------------- |
| `default`     | Action principale — CTA le plus visible.          |
| `destructive` | Actions irréversibles — suppressions.             |
| `outline`     | Actions secondaires — moins d'emphase.            |
| `secondary`   | Actions tertiaires — priorité visuelle faible.    |
| `ghost`       | Actions inline / barre d'outils — chrome minimal. |

## Size reference

| Size      | Height | Usage                              |
| --------- | ------ | ---------------------------------- |
| `sm`      | 36 px  | UI compacts, actions inline.       |
| `default` | 40 px  | Formulaires et dialogues standard. |
| `lg`      | 44 px  | Sections hero, CTA proéminents.    |
