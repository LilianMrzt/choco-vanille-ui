`Card` is a layout primitive for grouping related content into a distinct visual surface.
Compose it with `CardHeader`, `CardBody`, and `CardFooter` to build structured layouts.
`CardHeader` accepts `title`, `description` and `actions` props directly — no separate `CardTitle` / `CardDescription` sub-components needed.

<Source
  language="tsx"
  code={`import {
  Card, CardHeader, CardBody, CardFooter,
} from '@my-org/ui-kit';

<Card>
  <CardHeader
    title="Account settings"
    description="Manage your profile and preferences."
    titleAs="h3"
    actions={<IconButton icon="mdi:dots-vertical" aria-label="More" variant="ghost" color="primary" />}
  />
  <CardBody>
    <p>Your content goes here.</p>
  </CardBody>
  <CardFooter>
    <Button label="Save changes" variant="contained" color="primary" />
  </CardFooter>
</Card>`}
/>

## Accessibility

| Prop / Attribute | Required | Notes |
| ---------------- | -------- | ----- |
| `as` | No | Use `article` for self-contained content, `section` for themed groups, `aside` for supplementary content. Defaults to `div`. |
| `aria-label` / `aria-labelledby` | Conditional | Required on landmark elements (`section`, `aside`) when multiple instances co-exist on a page. |

`CardTitle` renders as `<h3>` by default. Override via the `titleAs` prop on `CardHeader` to maintain correct heading hierarchy on the page.

## API reference

### Card

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `as` | `'div' \| 'section' \| 'article' \| 'aside'` | `'div'` | HTML element to render. |
| `className` | `string` | — | Additional CSS classes merged onto the root element. |
| All `BoxProps` | — | — | All spacing, sizing, background and layout props from `Box` are available. |

### CardHeader

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `as` | `'div' \| 'header'` | `'div'` | HTML element to render. |
| `title` | `string` | — | Title text rendered as a heading. |
| `titleAs` | `'h1' \| 'h2' \| 'h3' \| 'h4' \| 'h5' \| 'h6'` | `'h3'` | Heading level. Adjust to maintain the correct document outline. |
| `titleProps` | `Omit<TypographyProps, 'children'>` | — | Extra props forwarded to the title `<Typography>` element. |
| `description` | `string` | — | Muted description rendered below the title. |
| `descriptionProps` | `Omit<TypographyProps, 'children'>` | — | Extra props forwarded to the description `<Typography>` element. |
| `actions` | `ReactNode` | — | Content rendered in the trailing corner (e.g. `IconButton`). |
| All `FlexProps` | — | — | All layout props from `Flex` / `Box` are available. |

### CardBody

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `as` | `'div' \| 'section'` | `'div'` | HTML element to render. |

### CardFooter

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `as` | `'div' \| 'footer'` | `'div'` | HTML element to render. |
