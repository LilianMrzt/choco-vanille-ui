<Subtitle>
  Polymorphic layout primitive — renders as any HTML element and exposes design-token-based props for display, spacing, sizing, background, overflow and positioning.
</Subtitle>

`Box` is the foundation of the layout system. `Flex` and `Grid` both extend it.
Use the `as` prop to render the semantically correct HTML element, and the token props (`p`, `m`, `bg`, `rounded`…) to apply design-system values without writing inline styles.

<Source
  language="tsx"
  code={`import { Box } from '@my-org/ui-kit';

// Basic container
<Box p="lg" bg="card" rounded="md">
  Content
</Box>

// Semantic element
<Box as="section" p="xl" bg="muted">
  <Typography variant="h2">Section title</Typography>
</Box>

// Centred full-height layout shell
<Box display="flex" h="screen" p="xl" bg="background">
  <Box m="auto" p="2xl" bg="card" rounded="lg">
    Modal-like content
  </Box>
</Box>`}
/>

## Accessibility

| Prop / Attribute | Required | Notes |
| ---------------- | -------- | ----- |
| `as` | No | Use semantic elements (`section`, `article`, `nav`, `main`…) instead of `div` when the container has structural meaning. |
| `aria-label` / `aria-labelledby` | Conditional | Required on landmark elements (`main`, `nav`, `aside`) when multiple instances of the same landmark co-exist on a page. |

`Box` does not manage focus — for interactive containers (modals, drawers), compose it with the appropriate Radix primitive or ARIA pattern.

## API reference

### Layout

| Prop       | Type                                                                                               | Default | Description                                   |
| ---------- | -------------------------------------------------------------------------------------------------- | ------- | --------------------------------------------- |
| `as`       | `'div' \| 'section' \| 'article' \| 'aside' \| 'main' \| 'header' \| 'footer' \| 'nav' \| 'ul' \| 'ol' \| 'li' \| 'form' \| 'fieldset' \| 'figure' \| 'figcaption' \| 'details' \| 'summary' \| 'dialog' \| 'address' \| 'span'` | `'div'` | HTML element to render. |
| `display`  | `'block' \| 'flex' \| 'inline-flex' \| 'inline' \| 'inline-block' \| 'grid' \| 'inline-grid' \| 'none' \| 'contents' \| 'flow-root'` | — | CSS `display` value. |
| `position` | `'static' \| 'relative' \| 'absolute' \| 'fixed' \| 'sticky'`                                    | —       | CSS `position` value.                         |
| `overflow` | `'visible' \| 'hidden' \| 'auto' \| 'scroll' \| 'clip'`                                          | —       | CSS `overflow` (both axes).                   |
| `overflowX`| `'visible' \| 'hidden' \| 'auto' \| 'scroll' \| 'clip'`                                          | —       | CSS `overflow-x`.                             |
| `overflowY`| `'visible' \| 'hidden' \| 'auto' \| 'scroll' \| 'clip'`                                          | —       | CSS `overflow-y`.                             |
| `w`        | `'full' \| 'screen' \| 'fit' \| 'min' \| 'max' \| 'auto'`                                        | —       | CSS `width` shorthand.                        |
| `h`        | `'full' \| 'screen' \| 'fit' \| 'min' \| 'max' \| 'auto'`                                        | —       | CSS `height` shorthand.                       |

### Spacing

All spacing props accept the same token scale: `none` · `px` · `xxs` · `xs` · `xs2` · `sm` · `md` · `lg` · `xl` · `2xl` · `3xl` · `4xl` · `5xl`.

| Prop  | CSS property        | Note                  |
| ----- | ------------------- | --------------------- |
| `p`   | `padding`           | All sides.            |
| `px`  | `padding-inline`    | Left + right.         |
| `py`  | `padding-block`     | Top + bottom.         |
| `pt`  | `padding-top`       |                       |
| `pr`  | `padding-right`     |                       |
| `pb`  | `padding-bottom`    |                       |
| `pl`  | `padding-left`      |                       |
| `m`   | `margin`            | Also accepts `'auto'`.|
| `mx`  | `margin-inline`     | Also accepts `'auto'`.|
| `my`  | `margin-block`      | Also accepts `'auto'`.|
| `mt`  | `margin-top`        | Also accepts `'auto'`.|
| `mr`  | `margin-right`      | Also accepts `'auto'`.|
| `mb`  | `margin-bottom`     | Also accepts `'auto'`.|
| `ml`  | `margin-left`       | Also accepts `'auto'`.|
| `gap` | `gap`               | For flex / grid children. |
| `gapX`| `column-gap`        |                       |
| `gapY`| `row-gap`           |                       |

### Appearance

| Prop      | Type                                                                                                      | Default | Description                        |
| --------- | --------------------------------------------------------------------------------------------------------- | ------- | ---------------------------------- |
| `rounded` | `'none' \| 'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl' \| 'full'`                                    | —       | CSS `border-radius` design token.  |
| `bg`      | `'transparent' \| 'background' \| 'card' \| 'muted' \| 'primary' \| 'primarySubtle' \| 'secondary' \| 'secondarySubtle' \| 'success' \| 'successSubtle' \| 'warning' \| 'warningSubtle' \| 'info' \| 'infoSubtle' \| 'destructive' \| 'destructiveSubtle'` | — | Semantic background color token. |
