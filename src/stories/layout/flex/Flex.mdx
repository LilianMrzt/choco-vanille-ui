<Subtitle>
  Flexbox layout primitive — extends Box with direction, wrap, alignment and justification props, all mapped to design tokens.
</Subtitle>

`Flex` renders a `display: flex` container. Use it for one-dimensional layouts — rows of buttons, stacked form fields, navigation bars, or any content that flows along a single axis.
All `Box` props (`p`, `m`, `bg`, `rounded`, `as`…) are available alongside the flex-specific variants.

<Source
  language="tsx"
  code={`import { Flex } from '@my-org/ui-kit';

// Horizontal row — centered items, medium gap
<Flex align="center" gap="md">
  <Avatar />
  <Typography variant="span">Jane Doe</Typography>
</Flex>

// Vertical stack — full-width items
<Flex direction="column" align="stretch" gap="lg">
  <Card />
  <Card />
  <Card />
</Flex>

// Responsive wrapping tag list
<Flex wrap="wrap" gap="sm">
  {tags.map(tag => <Tag key={tag} label={tag} />)}
</Flex>

// Space-between nav bar
<Flex as="nav" justify="between" align="center" px="lg" py="md" bg="card">
  <Logo />
  <NavLinks />
  <UserMenu />
</Flex>`}
/>

## Accessibility

| Prop / Attribute | Required | Notes |
| ---------------- | -------- | ----- |
| `as` | No | Use landmark/sectioning elements (`nav`, `header`, `section`…) when the container has structural meaning in the page. |
| `aria-label` / `aria-labelledby` | Conditional | Required when using a landmark `as` value with multiple instances of the same landmark on a page. |

Avoid `direction="row-reverse"` / `direction="column-reverse"` when it would create a mismatch between the visual order and DOM order — this confuses keyboard and screen-reader users.

## API reference

### Flex-specific props

| Prop        | Type                                                                          | Default   | Description                                      |
| ----------- | ----------------------------------------------------------------------------- | --------- | ------------------------------------------------ |
| `direction` | `'row' \| 'column' \| 'row-reverse' \| 'column-reverse'`                     | `'row'`   | CSS `flex-direction`.                            |
| `wrap`      | `'nowrap' \| 'wrap' \| 'wrap-reverse'`                                        | —         | CSS `flex-wrap`.                                 |
| `align`     | `'start' \| 'end' \| 'center' \| 'stretch' \| 'baseline'`                    | `'center'`| CSS `align-items` (cross-axis).                  |
| `justify`   | `'start' \| 'end' \| 'center' \| 'between' \| 'around' \| 'evenly' \| 'stretch'` | —     | CSS `justify-content` (main-axis).               |
| `inline`    | `boolean`                                                                     | `false`   | Switches to `display: inline-flex`.              |

### Inherited Box props (selection)

| Prop      | Description                                                      |
| --------- | ---------------------------------------------------------------- |
| `as`      | HTML element to render. Defaults to `div`.                       |
| `gap`     | Space between direct children — uses the spacing token scale.   |
| `gapX`    | Column gap only.                                                 |
| `gapY`    | Row gap only.                                                    |
| `p` / `px` / `py` | Padding (all sides / horizontal / vertical).           |
| `m` / `mx` / `my` | Margin (all sides / horizontal / vertical).            |
| `bg`      | Semantic background color token.                                 |
| `rounded` | Border-radius design token.                                      |
| `w` / `h` | Width / height shorthand.                                        |

> See the **Box** documentation for the complete list of inherited props.

## Justify vs Align

| Prop      | CSS property       | Axis (default `direction="row"`) |
| --------- | ------------------ | -------------------------------- |
| `justify` | `justify-content`  | Main axis → horizontal           |
| `align`   | `align-items`      | Cross axis → vertical            |

When `direction="column"`, the axes flip: `justify` controls vertical distribution and `align` controls horizontal alignment.
