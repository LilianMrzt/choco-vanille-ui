  Accessible tooltip overlay — controlled or uncontrolled, 12 positions, animated transitions, and full keyboard support.
</Subtitle>

Wrap any focusable element with `<Tooltip>` and provide the `content` prop to display contextual information on hover or focus.

<Source
  language="tsx"
  code={`import { Tooltip, Button } from '@my-org/ui-kit';

// Basic usage
<Tooltip content="Save the current document">
  <Button label="Save" />
</Tooltip>

// Custom side and delay
<Tooltip content="More options" side="right" delayDuration={500}>
  <Button variant="ghost" label="⚙" />
</Tooltip>

// Controlled
<Tooltip content="Always visible" open={true}>
  <Button label="Trigger" />
</Tooltip>`}
/>

## Accessibility

| Prop / Attribute | Required | Notes |
| ---------------- | -------- | ----- |
| `content` | ✅ Required | Must be supplementary — never put task-critical info exclusively in a tooltip. |
| `children` | ✅ Required | Must be a single focusable element; add `tabIndex={0}` when wrapping a non-focusable node. |
| `delayDuration` | No | Set to `0` in tests or when the tooltip acts as a persistent label. |
| `disabled` | No | When `true`, suppresses the tooltip entirely. |
| `open` | No | Controlled open state — pair with `onOpenChange` for custom show/hide logic. |
