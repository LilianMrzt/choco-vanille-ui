  Composable popover overlay — controlled or uncontrolled, 12 positions,
  animated transitions, and full keyboard support.

Use `<Popover>` to display rich content, forms, or actions attached to a trigger element.

<Source
  language="tsx"
  code={`import { Popover, Button } from '@my-org/ui-kit';

<Popover>
  <Popover.Trigger asChild>
    <Button label="Open popover" />
  </Popover.Trigger>

  <Popover.Content>
    <p>Place any content here: text, forms, or buttons.</p>
  </Popover.Content>
</Popover>`}
/>

## Accessibility

| Prop / Attribute            | Required    | Notes                                                                                       |
| --------------------------- | ----------- | ------------------------------------------------------------------------------------------- |
| Trigger (focusable element) | ✅ Required | Use `asChild` on `Popover.Trigger` to forward the ref to your own `Button` or `IconButton`. |
| `open`                      | No          | Controlled open state — pair with `onOpenChange` for custom show/hide logic.                |
| `modal`                     | No          | @default `true`. Blocks outside interaction and aria-hides the rest of the page when open.  |
| `position`                  | No          | Shorthand combining `side` + `align`. Takes precedence over `side` and `align` when set.    |
