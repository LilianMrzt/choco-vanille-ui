## Accessibility

| Prop / Attribute | Required | Notes |
| ---------------- | -------- | ----- |
| Focusable trigger | ✅ Required | Use `asChild` on `DropdownMenuTrigger` to forward behaviour to your own `Button` or `IconButton`. |
| `shortcut` (on `DropdownMenuItem`) | No | Purely decorative — wire actual `keydown` handlers separately in your application. |
| `destructive` (on `DropdownMenuItem`) | No | Applies a danger color to warn users before irreversible actions. |
| `disabled` (on any item) | No | Marks the item as unavailable; it remains visible and announced by screen readers. |

Keyboard navigation is built in: **Enter** / **Space** to open, **Arrow keys** to navigate, **Escape** to close.

## Sub-components

| Sub-component | What it is |
| ------------- | ---------- |
| `DropdownMenu` | Root context provider for the entire menu. |
| `DropdownMenuTrigger` | The element that toggles the menu open / closed. |
| `DropdownMenuContent` | The floating panel that contains menu items. |
| `DropdownMenuGroup` | A logical grouping wrapper for related items. |
| `DropdownMenuItem` | A single actionable item with optional icons and shortcut hint. |
| `DropdownMenuCheckboxItem` | A toggleable item that shows a checkmark indicator when checked. |
| `DropdownMenuRadioGroup` | Container for a set of mutually exclusive radio items. |
| `DropdownMenuRadioItem` | A single radio option inside a `DropdownMenuRadioGroup`. |
| `DropdownMenuLabel` | A non-interactive section heading for a group of items. |
| `DropdownMenuSeparator` | A horizontal line that visually separates sections. |
| `DropdownMenuSub` | Root wrapper for a nested sub-menu. |
| `DropdownMenuSubTrigger` | An item that reveals a nested sub-menu on hover or keyboard focus. |
| `DropdownMenuSubContent` | The floating panel for a nested sub-menu. |
