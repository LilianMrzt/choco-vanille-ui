The `DropdownMenu` is a **compound component**: import `DropdownMenu` and access each building block via dot notation.

<Source
  language="tsx"
  code={`import { DropdownMenu } from '@my-org/ui-kit';

<DropdownMenu>
  <DropdownMenu.Trigger asChild>
    <Button label="Open" endIcon="mdi:chevron-down" />
  </DropdownMenu.Trigger>

  <DropdownMenu.Content>
    <DropdownMenu.Label label="My Account" />
    <DropdownMenu.Separator />

    <DropdownMenu.Group>
      <DropdownMenu.Item label="Profile" startIcon="mdi:account-outline" shortcut="⇧⌘P" />
      <DropdownMenu.Item label="Settings" startIcon="mdi:cog-outline" shortcut="⌘S" />
    </DropdownMenu.Group>

    <DropdownMenu.Separator />

    <DropdownMenu.Item label="Log out" startIcon="mdi:logout" destructive shortcut="⇧⌘Q" />
  </DropdownMenu.Content>
</DropdownMenu>`}
/>

## Accessibility

| Prop / Attribute | Required | Notes |
| ---------------- | -------- | ----- |
| Focusable trigger | ✅ Required | Use `asChild` on `DropdownMenu.Trigger` to forward behaviour to your own `Button` or `IconButton`. |
| `shortcut` (on `DropdownMenu.Item`) | No | Purely decorative — wire actual `keydown` handlers separately in your application. |
| `destructive` (on `DropdownMenu.Item`) | No | Applies a danger color to warn users before irreversible actions. |
| `disabled` (on any item) | No | Marks the item as unavailable; it remains visible and announced by screen readers. |

Keyboard navigation is built in: **Enter** / **Space** to open, **Arrow keys** to navigate, **Escape** to close.

## Sub-components

| Sub-component | What it is | Place inside |
| ------------- | ---------- | ------------ |
| `DropdownMenu` | Root — manages open/close state and provides context to all children. | Top level |
| `DropdownMenu.Trigger` | The element that toggles the menu open / closed. Use `asChild` to delegate to your own button. | `DropdownMenu` |
| `DropdownMenu.Content` | The floating panel that contains menu items. | `DropdownMenu` |
| `DropdownMenu.Label` | A non-interactive section heading that names the group below it. | `DropdownMenu.Content` |
| `DropdownMenu.Separator` | A horizontal line that visually separates sections. | `DropdownMenu.Content` |
| `DropdownMenu.Group` | A logical grouping wrapper for related items — no visual output. | `DropdownMenu.Content` |
| `DropdownMenu.Item` | A single actionable item with optional `startIcon`, `endIcon` and `shortcut`. | `DropdownMenu.Content` or `DropdownMenu.Group` |
| `DropdownMenu.CheckboxItem` | A toggleable item that shows a checkmark when `checked`. | `DropdownMenu.Content` or `DropdownMenu.Group` |
| `DropdownMenu.RadioGroup` | Container for mutually exclusive radio options; holds the current `value`. | `DropdownMenu.Content` |
| `DropdownMenu.RadioItem` | A single radio option; selected when its `value` matches the parent `DropdownMenu.RadioGroup`. | `DropdownMenu.RadioGroup` |
| `DropdownMenu.Sub` | Root wrapper for a nested sub-menu — wraps `SubTrigger` + `SubContent`. | `DropdownMenu.Content` or `DropdownMenu.Group` |
| `DropdownMenu.SubTrigger` | An item that reveals the nested sub-menu on hover or keyboard focus. | `DropdownMenu.Sub` |
| `DropdownMenu.SubContent` | The floating panel for the nested sub-menu content. | `DropdownMenu.Sub` |
