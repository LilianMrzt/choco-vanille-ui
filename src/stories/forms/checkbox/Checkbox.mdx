<Subtitle>
  Binary selection control (checked / unchecked) — keyboard accessible, supporting both controlled and uncontrolled modes, with an optional label.
</Subtitle>

Use `checked` + `onCheckedChange` for **controlled** mode, or `defaultChecked` for **uncontrolled** mode.
Pass a `label` to display a clickable label automatically associated to the control via `htmlFor`.

<Source
  language="tsx"
  code={`import { Checkbox } from '@my-org/ui-kit';

// Uncontrolled
<Checkbox label="Accept terms and conditions" defaultChecked />

// Controlled
<Checkbox
  label="Receive notifications"
  checked={checked}
  onCheckedChange={(val) => setChecked(val === true)}
/>

// Without label (for custom composition)
<Checkbox
  id="my-checkbox"
  aria-label="Enable dark mode"
  checked={checked}
  onCheckedChange={setChecked}
/>`}
/>

## Accessibility

| Prop / Attribute | Required | Notes |
| ---------------- | -------- | ----- |
| `label` | Conditional | Displayed next to the control; auto-linked to the input via `htmlFor`. Provide one whenever possible. |
| `aria-label` / `aria-labelledby` | Conditional | Required when `label` is omitted — the control must always have an accessible name. |
| `disabled` | No | Keeps the control visible and announced by screen readers; do not hide unavailable options. |
| `required` | No | Marks the field as required for native form validation. |
| `name` / `value` | No | Used for native form submission. |

## API reference

| Prop              | Type                                             | Default | Description                                                                          |
| ----------------- | ------------------------------------------------ | ------- | ------------------------------------------------------------------------------------ |
| `checked`         | `boolean \| 'indeterminate'`                     | —       | Controlled state. Use with `onCheckedChange`.                                        |
| `defaultChecked`  | `boolean`                                        | `false` | Initial uncontrolled state.                                                          |
| `onCheckedChange` | `(checked: boolean \| 'indeterminate') => void`  | —       | Callback fired on every state change.                                                |
| `label`           | `string`                                         | —       | Label displayed to the right of the control, linked via `htmlFor`.                   |
| `id`              | `string`                                         | auto    | HTML id of the button. Auto-generated when `label` is provided without an explicit `id`. |
| `disabled`        | `boolean`                                        | `false` | Disables the control and visually dims the label.                                    |
| `className`       | `string`                                         | —       | Additional CSS classes applied to the root button.                                   |
