`TextField` wraps a native `<input>` and a Radix `Label` to provide automatic `htmlFor` / `id` binding.
Use `error` to switch to the destructive state and surface validation feedback, and `helperText` for hints.

<Source
  language="tsx"
  code={`import { TextField } from '@my-org/ui-kit';

// Uncontrolled with label
<TextField label="Email" placeholder="you@example.com" />

// Controlled with inline validation
<TextField
  label="Email"
  value={email}
  onChange={(e) => setEmail(e.target.value)}
  error={!email ? 'Email is required' : undefined}
/>

// With helper text
<TextField
  label="Username"
  helperText="Letters and underscores only."
/>

// Without visible label (use aria-label for accessibility)
<TextField placeholder="Search…" aria-label="Search" />`}
/>

## Accessibility

| Prop / Attribute | Required | Notes |
| ---------------- | -------- | ----- |
| `label` | Conditional | Auto-linked to the input via `htmlFor` / `id`. Provide one whenever possible. |
| `aria-label` / `aria-labelledby` | Conditional | Required when `label` is omitted — the input must always have an accessible name. |
| `error` | No | Sets `aria-invalid` and links the message via `aria-describedby`. |
| `helperText` | No | Linked via `aria-describedby`; hidden when `error` is present. |
| `disabled` | No | Dims the label and prevents interaction while keeping the field announced. |
| `required` | No | Native form validation marker. |

## API reference

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `label` | `string` | — | Visible label rendered above the input, linked via Radix Label. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Controls the height and font size of the input. |
| `helperText` | `string` | — | Hint text shown below the input. Hidden when `error` is set. |
| `error` | `string` | — | Error message. Sets `aria-invalid` and applies destructive styles. |
| `disabled` | `boolean` | `false` | Disables interaction and dims the label. |
| `required` | `boolean` | `false` | Marks the field as required for native form validation. |
| `placeholder` | `string` | — | Placeholder text shown when the input is empty. |
| `id` | `string` | auto | HTML `id` of the input. Auto-generated when `label` is provided. |
| `className` | `string` | — | Additional CSS classes applied to the `<input>` element. |
