  An accessible date-picker calendar with single, multiple and range selection — built on top of `react-day-picker` with a custom month/year picker and no native dropdowns.

`Calendar` renders a self-contained date picker. The header shows **← Month Year →** in day view.
Clicking the **Month Year** button opens a year picker (3 × 4 grid), then a month picker, then returns to the day view.
Arrow keys navigate within the year and month grids.

<Source
  language="tsx"
  code={`import { Calendar } from '@my-org/ui-kit';

// Single date
const [date, setDate] = useState<Date>();
<Calendar mode="single" selected={date} onSelect={setDate} />

// Range selection
const [range, setRange] = useState<DateRange>();
<Calendar mode="range" selected={range} onSelect={setRange} />

// Date of birth — century of years, no future dates
<Calendar
  mode="single"
  startYear={1900}
  endYear={new Date().getFullYear()}
  disabled={{ after: new Date() }}
  selected={dob}
  onSelect={setDob}
/>`}

## Accessibility

| Prop / Attribute | Required | Notes |
| ---------------- | -------- | ----- |
| `mode` | Yes | Determines selection behaviour. Screen readers announce the current selection mode. |
| `aria-label` on wrapping element | Recommended | Label the calendar region, e.g. `aria-label="Date picker"`. |
| `disabled` | No | Disabled days receive `aria-disabled` and cannot be focused. |
| Keyboard — day grid | — | `Tab` enters the grid. `Arrow` keys move between days. `Enter` / `Space` selects. |
| Keyboard — year/month picker | — | Opening the picker auto-focuses the selected item. `Arrow` keys move in a 3-column grid. `Enter` / `Space` confirms. |
| `startYear` / `endYear` | No | Constrain the year picker range. Always set `endYear` when `disabled={{ after: new Date() }}` to avoid unreachable future years. |

## API reference

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `mode` | `'single' \| 'multiple' \| 'range'` | `'single'` | Selection behaviour. |
| `selected` | `Date \| Date[] \| DateRange` | — | Controlled selected value. |
| `onSelect` | `function` | — | Called when the selection changes. |
| `startYear` | `number` | `currentYear - 100` | Earliest selectable year in the picker. |
| `endYear` | `number` | `currentYear + 10` | Latest selectable year in the picker. |
| `disabled` | `Matcher \| Matcher[]` | — | Dates or rules that cannot be selected. |
| `showOutsideDays` | `boolean` | `true` | Show days from adjacent months in the day grid. |
| `month` | `Date` | — | Controlled displayed month. |
| `defaultMonth` | `Date` | `new Date()` | Initial displayed month (uncontrolled). |
| `onMonthChange` | `(month: Date) => void` | — | Called when the displayed month changes. |
| `weekStartsOn` | `0 \| 1 \| 2 \| 3 \| 4 \| 5 \| 6` | `1` (Monday) | First day of the week. `0` = Sunday, `1` = Monday … `6` = Saturday. |
| `className` | `string` | — | Additional class applied to the root element. |
