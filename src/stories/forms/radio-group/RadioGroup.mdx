  Single-selection radio group — keyboard accessible, supporting both controlled and uncontrolled modes, with horizontal or vertical orientation.

`RadioGroup` is a **compound component**: use `RadioGroup.Item` for each option inside the group.
Use `value` + `onValueChange` for **controlled** mode, or `defaultValue` for **uncontrolled** mode.

<Source
  language="tsx"
  code={`import { RadioGroup } from '@my-org/ui-kit';

// Uncontrolled
<RadioGroup defaultValue="system">
  <RadioGroup.Item value="light" label="Light" />
  <RadioGroup.Item value="dark" label="Dark" />
  <RadioGroup.Item value="system" label="System" />
</RadioGroup>

// Controlled
<RadioGroup value={theme} onValueChange={setTheme}>
  <RadioGroup.Item value="light" label="Light" />
  <RadioGroup.Item value="dark" label="Dark" />
  <RadioGroup.Item value="system" label="System" />
</RadioGroup>

// Horizontal layout
<RadioGroup defaultValue="md" orientation="horizontal" style={{ flexDirection: 'row', gap: '1.5rem' }}>
  <RadioGroup.Item value="sm" label="Small" />
  <RadioGroup.Item value="md" label="Medium" />
  <RadioGroup.Item value="lg" label="Large" />
</RadioGroup>`}
/>

## Accessibility

| Prop / Attribute | Required | Notes |
| ---------------- | -------- | ----- |
| `aria-label` / `aria-labelledby` on `RadioGroup` | Conditional | Required when there is no visible group label — announces the group purpose to screen readers. |
| `label` on `RadioGroup.Item` | Conditional | Visible label; auto-linked to the radio button via `htmlFor`. Provide one whenever possible. |
| `aria-label` on `RadioGroup.Item` | Conditional | Required when `label` is omitted — each option must have an accessible name. |
| `disabled` (item) | No | Marks a single option as unavailable; it is skipped by keyboard navigation. |
| `disabled` (group) | No | Disables all items at once — use when the entire selection is locked. |
| `orientation` | No | `'horizontal'` or `'vertical'` — informs assistive technology of the expected arrow-key direction. |

## Sub-components

| Sub-component | Role in compound |
| ------------- | ---------------- |
| `RadioGroup` | Root — manages single-selection state, keyboard navigation and orientation. |
| `RadioGroup.Item` | A single radio option with an optional visible label, placed directly inside `RadioGroup`. |

## API reference — `<RadioGroup>`

| Prop            | Type                          | Default      | Description                                            |
| --------------- | ----------------------------- | ------------ | ------------------------------------------------------ |
| `value`         | `string`                      | —            | Controlled value. Use with `onValueChange`.            |
| `defaultValue`  | `string`                      | —            | Initial uncontrolled value.                            |
| `onValueChange` | `(value: string) => void`     | —            | Callback fired when the selection changes.             |
| `disabled`      | `boolean`                     | `false`      | Disables all items in the group.                       |
| `orientation`   | `'horizontal' \| 'vertical'`  | `'vertical'` | Orientation used for keyboard navigation.              |
| `className`     | `string`                      | —            | Additional CSS classes on the root container.          |

## API reference — `<RadioGroup.Item>`

| Prop        | Type      | Default | Description                                                                          |
| ----------- | --------- | ------- | ------------------------------------------------------------------------------------ |
| `value`     | `string`  | —       | **Required.** Value identifying this item within the group.                          |
| `label`     | `string`  | —       | Label displayed to the right of the button, linked via `htmlFor`.                    |
| `id`        | `string`  | auto    | HTML id of the button. Auto-generated when `label` is provided without an explicit `id`. |
| `disabled`  | `boolean` | `false` | Disables this item only.                                                             |
| `className` | `string`  | —       | Additional CSS classes on the radio button.                                          |
