`RadioGroup` est un composant **compound** : `RadioGroup` gère l'état de sélection et chaque `RadioItem` représente une option.
Utilisez `value` + `onValueChange` pour un mode **contrôlé**, ou `defaultValue` pour un mode **non contrôlé**.

<Source
  language="tsx"
  code={`import { RadioGroup, RadioItem } from '@my-org/ui-kit';

// Non contrôlé
<RadioGroup defaultValue="system">
  <RadioItem value="light" label="Clair" />
  <RadioItem value="dark" label="Sombre" />
  <RadioItem value="system" label="Système" />
</RadioGroup>

// Contrôlé
<RadioGroup value={theme} onValueChange={setTheme}>
  <RadioItem value="light" label="Clair" />
  <RadioItem value="dark" label="Sombre" />
  <RadioItem value="system" label="Système" />
</RadioGroup>

// Disposition horizontale
<RadioGroup defaultValue="md" orientation="horizontal" style={{ flexDirection: 'row', gap: '1.5rem' }}>
  <RadioItem value="sm" label="Small" />
  <RadioItem value="md" label="Medium" />
  <RadioItem value="lg" label="Large" />
</RadioGroup>`}
/>

## API reference — `<RadioGroup>`

| Prop            | Type                        | Default      | Description                                             |
| --------------- | --------------------------- | ------------ | ------------------------------------------------------- |
| `value`         | `string`                    | —            | Valeur contrôlée. Utiliser avec `onValueChange`.        |
| `defaultValue`  | `string`                    | —            | Valeur initiale non contrôlée.                          |
| `onValueChange` | `(value: string) => void`   | —            | Callback déclenché lors d'un changement de sélection.   |
| `disabled`      | `boolean`                   | `false`      | Désactive tous les items du groupe.                     |
| `orientation`   | `'horizontal' \| 'vertical'` | `'vertical'` | Orientation pour la navigation clavier.                |
| `className`     | `string`                    | —            | Classes CSS supplémentaires sur le conteneur racine.    |

## API reference — `<RadioItem>`

| Prop        | Type      | Default | Description                                                               |
| ----------- | --------- | ------- | ------------------------------------------------------------------------- |
| `value`     | `string`  | —       | **Requis.** Valeur identifiant cet item dans le groupe.                   |
| `label`     | `string`  | —       | Libellé affiché à droite du bouton, lié via `htmlFor`.                    |
| `id`        | `string`  | auto    | ID HTML du bouton. Auto-généré si `label` est fourni sans `id` explicite. |
| `disabled`  | `boolean` | `false` | Désactive uniquement cet item.                                            |
| `className` | `string`  | —       | Classes CSS supplémentaires sur le bouton radio.                          |

## Accessibilité

- Le rôle ARIA `radio` et `radiogroup` sont gérés nativement par `@radix-ui/react-radio-group`.
- `aria-checked` est mis à jour automatiquement.
- Navigation clavier : `Tab` pour entrer dans le groupe, `↑` / `↓` (ou `←` / `→` en horizontal) pour changer d'option.
- Le focus visible est matérialisé par un anneau de focus utilisant `vars.color.ring`.
- Lier un `label` via `htmlFor` permet de cliquer sur le texte pour sélectionner l'option.
