## 1 — The `Icon` component

The `Icon` component renders a locally bundled SVG component passed to the `icon` prop. The library keeps its internal icon registry private; consumers provide the SVG component they need.

<Source
    language="tsx"
    code={`import { Icon } from '@choco-vanille/ui'
import SearchIcon from './assets/SearchIcon.svg?react'
import TriangleAlertIcon from './assets/TriangleAlertIcon.svg?react'

// Decorative icon — hidden from screen readers

<Icon icon={SearchIcon} />

// Semantic icon — announced with an accessible label

<Icon icon={TriangleAlertIcon} aria-label="Warning" />`}
/>

## 2 — Providing local SVG components

Import the SVG components you want to use and keep a registry in your consumer
project. The registry used by the library itself is internal and is not part of
the public package API.

This gives you:

### Using local icons in your components

Keep the registry in the consumer project, for example in
`src/icons/registry.ts`:

<Source
    language="tsx"
    code={`import SearchIcon from './assets/SearchIcon.svg?react'
import TriangleAlertIcon from './assets/TriangleAlertIcon.svg?react'
import CloseIcon from './assets/CloseIcon.svg?react'

export const IconRegistry = {
    search: SearchIcon,
    warning: TriangleAlertIcon,
    close: CloseIcon,
} as const`}
/>

Then import that registry from the consumer project, not from the UI kit:

<Source
    language="tsx"
    code={`import { Icon } from '@choco-vanille/ui'
import { IconRegistry } from '@/icons/registry'

<Icon icon={IconRegistry.search} />
<Icon icon={IconRegistry.warning} size="lg" aria-label="Warning" />
<Icon icon={IconRegistry.close} spin />`}
/>

### SVG setup

Configure your project to transform SVG files into React components with
`vite-plugin-svgr`. Without this Vite plugin, the `?react` imports used by the
registry will not work.

<Source language="bash" code={`pnpm add -D vite-plugin-svgr`} />

<Source
    language="ts"
    code={`import react from '@vitejs/plugin-react'
import { defineConfig } from 'vite'
import svgr from 'vite-plugin-svgr'

export default defineConfig({
    plugins: [react(), svgr()],
})`}
/>

### Choosing icons

Use the local SVG that matches the component's meaning. Library components use
their private registry internally; consumer components should use the
consumer-owned registry instead.

### Naming keys

```
✅  search, chevronRight, user, imagePlus
❌  SearchIcon, search-icon, SEARCH_ICON, icon_search
```

Use **camelCase** and **semantic names** (what the icon represents) rather than descriptive names (its shape).
