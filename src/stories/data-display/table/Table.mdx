## Accessibility

| Element / Prop | Notes |
| --- | --- |
| `Table.Caption` | Provides the accessible name for the table. Always include one, or use `aria-label` on `Table` when no caption is present. |
| `Table.Head` (`<th>`) | Maps to `role="columnheader"` automatically — no extra ARIA needed for simple tables. |
| `scope="col"` | Add to `Table.Head` for explicit column scoping in complex or multi-level header tables. |
| `sortDirection` | Sets `aria-sort="ascending"` / `"descending"` / `"none"` on `<th>` automatically. |
| `selectable` | Sets `aria-selected` on `<tr>` automatically when combined with `selected`. |
| `aria-label` | Use on `Table` when `Table.Caption` is omitted. |
| Keyboard | Rows with `selectable` + `onClick` are pointer-activated only — add `onKeyDown` or `role="button"` for full keyboard support. |

## Sub-component reference

| Component | Element | Key props | Role in compound |
| --- | --- | --- | --- |
| `Table` | `<table>` | `size`, `striped`, `bordered`, `fixed` | Root — configures size, striping and layout for all descendant cells. |
| `Table.Caption` | `<caption>` | — | Accessible name for the table — always include one (or use `aria-label` on `Table`). |
| `Table.ColGroup` | `<colgroup>` | — | Optional column width declarations; requires `fixed` on `Table` to take effect. |
| `Table.Col` | `<col>` | `width`, `minWidth`, `maxWidth` | Defines the width of a single column inside `Table.ColGroup`. |
| `Table.Header` | `<thead>` | — | Groups all header rows; place one or more `Table.Row` with `Table.Head` cells inside. |
| `Table.Body` | `<tbody>` | — | Groups the data rows; place `Table.Row` with `Table.Cell` cells inside. |
| `Table.Footer` | `<tfoot>` | — | Groups summary rows (e.g. totals); place `Table.Row` with `Table.Cell` cells inside. |
| `Table.Row` | `<tr>` | `hoverable`, `selectable`, `selected`, `intent` | A single row — use inside `Table.Header`, `Table.Body` or `Table.Footer`. |
| `Table.Head` | `<th>` | `align`, `sortable`, `sortDirection` | A column header cell — use inside a `Table.Row` within `Table.Header`. |
| `Table.Cell` | `<td>` | `align`, `numeric`, `truncate` | A data cell — use inside a `Table.Row` within `Table.Body` or `Table.Footer`. |
